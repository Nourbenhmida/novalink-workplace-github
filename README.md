# NovaLink Workplace

## Fonctionnalité : Recherche d'une salle disponible

Cette fonctionnalité permet aux utilisateurs de rechercher une salle selon une date et une capacité.

### Critères d'acceptation

1. L'utilisateur peut sélectionner une date de réservation.
2. L'utilisateur peut indiquer le nombre de personnes.
3. Le système affiche les salles disponibles ou un message indiquant qu'aucune salle n'est disponible.
